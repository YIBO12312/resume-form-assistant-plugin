    档案字段

    带 的是网申几乎必填项。填得越全，一键填充的命中率越高。

    经历与技能（可重复区块）

    大厂网申（北森 / 大易 / Moka 那类系统）的「教育经历、语言能力、证书、技能、获奖情况、实习经历」 都是可以点「添加」加多条的区块，每条的字段名一模一样。 这里填几条，页面上对应的第几条就会被自动填上——所以不用你在页面上一条条手填。 顺序请按页面上的显示顺序（一般是时间倒序）。

    简历附件与证件照

    文件都存在本机浏览器里，填表时会自动挂到页面的「上传简历 / 证件照」控件上。建议 5MB 以内。

    自定义字段

    遇到插件字典里没有的字段（例如「是否接受外派」「导师姓名」），在这里加一条；别名用英文逗号分隔，会把页面上这些文字识别成同一个字段。字段值在「档案字段 → 自定义字段」里填写。

    站点规则

    当某个网站字段名太特殊、自动识别不准时，可以在页面上用插件面板手动指定一次，之后会记住。这里可以看到并删除已记录的内容。

    通用设置

    导入 / 导出

    导出会把全部档案与设置存成一个 JSON 文件（不含简历附件本身），换电脑时导入即可。

    使用提示

    • 在网申页按 Alt+Shift+J 一键填充；Alt+Shift+K 打开识别面板。
    • 也可以点工具栏上的插件图标，或用页面右下角的悬浮球。
    • 填完记得核对：插件只负责把值写进控件，不保证网站的校验规则都通过。
    • 部分自绘下拉（Ant Design / Element UI）会自动展开选择；如果失败，面板里会标红并说明原因。
    • 填错了就点面板里的「撤销」，会恢复成填充前的样子。

    装好了，三步就能用

    1. 在这里补全下面标红的空字段（尤其是性别、出生年月这类网申必填项）。
    2. 在「简历附件」里选一份简历文件。
    3. 打开网申页面，按 Alt+Shift+J。
