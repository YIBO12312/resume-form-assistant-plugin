# 网申助手 · Resume Form Assistant

> 一键填完网申表单的 Edge / Chrome 扩展。打开申请页按 `Alt+Shift+J`，
> 姓名、手机、邮箱、学校、专业、学历、毕业时间、实习与项目经历全部自动填好，简历附件也能自动挂上。

**纯本地运行 · 不联网 · 不上传 · 零依赖 · 零构建**

[快速开始](#-快速开始) · [功能](#-它做什么) · [识别原理](#-它怎么认字段的) · [隐私](#-隐私) · [测试](#-自检与测试) · [项目结构](#-项目结构)

## ✨ 它做什么

| | |
| --- | --- |
| **一键填充** | 快捷键 / 悬浮球 / 工具栏图标 / 右键菜单，四种触发方式 |
| **先看再填** | 填充前可以预览：每个字段靠什么认出来的、置信多少，逐条勾选 |
| **填错能撤** | 精确记录填充前的值，一键还原 |
| **兼容框架** | 用原生 setter + `input`/`change` 事件写值，React / Vue 站点能真正读到 |
| **自绘下拉** | 支持 Ant Design / Element UI / iView / Semi / Arco 的下拉自动展开选择 |
| **简历附件** | 自动把本地简历挂到「上传简历」文件控件上 |
| **多套档案** | 投不同方向各存一份档案，投递时切换 |
| **跨 iframe** | 表单嵌在内层框架里也能填，`allFrames` 一起处理 |
| **可重复区块** | 教育经历 / 语言 / 证书 / 技能 / 获奖 / 实习能一次填多条：页面上第 N 条自动取档案里第 N 条 |
| **自定义字段** | 字典里没有的字段，加一条别名就能识别 |
| **站点规则** | 特别难认的网站，手动指定一次之后会被记住 |

## 🚀 快速开始

### 1. 下载

```bash
git clone https://github.com/YIBO12312/resume-form-assistant-plugin.git
```

或者点页面右上角 **Code → Download ZIP** 解压。

### 2. 加载到浏览器

1. 打开 `edge://extensions/`（Chrome 用 `chrome://extensions/`）
2. 打开左下角 **「开发人员模式」**
3. 点 **「加载解压缩的扩展」**，选择本仓库根目录（含 `manifest.json` 的那一层）

> Windows 用户也可以直接双击 `安装到Edge.bat`，它会同时打开扩展页和文件夹。

### 3. 填档案（重要）

**本仓库出厂时档案是空的** —— 81 个字段全部留空。
这是刻意的：仓库公开，绝不能把任何人的真实简历数据打包进去。

装好后浏览器会自动打开设置页，三种方式任选：

- **逐项填写**：设置页 →「档案字段」，带红点的必填项优先
- **导入示例**：设置页 →「导入 / 导出」→ 导入 `examples/demo-profile.json`（虚构的「张三」，可直接改）
- **导入备份**：导入你自己的档案 JSON

然后在「**简历附件**」里选一份本地简历文件。左侧会一直提示「还有 N 个必填项是空的」，补完即消失。

### 4. 开始填表

打开招聘网站的申请页（装完插件后**需要刷新一次页面**），按：

| 快捷键 | 作用 |
| --- | --- |
| `Alt` + `Shift` + `J` | 一键填充 |
| `Alt` + `Shift` + `K` | 只看识别结果，不填 |

> 首次用某个网站，建议先 `Alt+Shift+K` 预览，确认没认错再填。
> 填完请自行核对再提交 —— 插件只负责把值写进控件，不保证网站的校验规则都通过。

## 🧠 它怎么认字段的

网申系统的表单结构五花八门，所以识别引擎同时从 **11 个来源**取证，每个来源权重不同：

| 来源 | 权重 | 说明 |
| --- | --- | --- |
| `label` | 100 | `<label for="...">` 或包裹型 label |
| `tableHead` | 96 | `thead` 里对应的表头列 |
| `rowLabel` | 95 | 表格同行第一列的标签（网申最常见布局） |
| `dt` | 95 | `<dl>` 里对应的 `<dt>` |
| `groupLabel` | 93 | 单选/复选组：把「性别 男 女」里的选项文本剔掉，剩下的题干 |
| `aria` / `title` / `data-*` | 86~90 | 无障碍标签与自定义属性 |
| `placeholder` | 84 | 输入提示 |
| `ancestorSibling` | 67~82 | **祖先容器的紧邻前兄弟**：`<div class="fx-field"><div class="field-label">姓名</div><div class="field-component"><input></div></div>`。简道云 / 帆软 / 明道云 / 宜搭这类低代码平台全是这种结构，input 常常没有任何 id / name / placeholder / aria |
| `sibling` / `ancestor` | 65~82 | 紧邻的前置文字、只包着一个控件的外层容器 |
| `containerOwn` | 63~78 | 容器里「不属于本控件那一支」的文字，用于「标签 + 控件 + 隐藏 input」这类容器（日期选择器等） |
| `name` / `id` / `class` | 44~62 | 属性兜底 |

`ancestorSibling` / `containerOwn` 这两条是启发式来源，带三重护栏，否则极易误填：

1. **跳过整块字段行**：含控件的块直接跳过，避免把上一行的标签算到本行；
2. **跳过类名表明是「字段行」的块**：低代码平台里的自绘下拉（性别 / 籍贯 / 学位）内部**没有原生控件**，第 1 条护栏对它们失效 —— 实测中真实的「学号」输入框就被上一行的「学位」抢走了。判断顺序是「先看像不像标签，再看像不像字段行」；
3. **只接受短文本（≤24 字）且排除分区标题**：子表单的列头会被拼成长串（实测出现过「开始时间结束时间公司职位工作描述…」靠子串命中），分区标题（教育经历 / 实习经历）也不该被当成字段标签。

在此之上还有几条关键规则：

- **归一化**：全角转半角、去掉空格标点，并剔除「请输入 / 请选择 / 必填 / `*`」等噪声词，
  所以 `姓 名：`、`*姓名`、`请输入姓名（必填）` 都能认出来
- **最长别名胜出**：`紧急联系人姓名` 一定赢过 `姓名`，不会把别人填成你自己
- **硬排除**：`电话` 字段遇到「紧急联系人电话」「固定电话」直接放弃，绝不瞎填
- **分区推断**：向上找最近的「教育经历 / 实习经历 / 项目经历」标题，
  同一个表单里两组「开始时间 / 结束时间」不会串
- **不猜**：没有分区信息时，裸的「开始时间」干脆不填；搜索框、验证码、密码框、隐藏元素一律跳过
- **英文弱别名**：`Name` / `Gender` / `Email` / `Mobile` 能认，但权重被压低 22 分，
  所以 `name="userName"`、`class="schoolname"` 这类噪声不会误触发
- **日期自适应**：按控件类型与 placeholder 自动改写为 `YYYY-MM-DD`、`YYYY-MM`、`YYYY年MM月`、
  `202309` 等；`maxlength=4` 就只填年份；「至今」原样保留
- **选项模糊匹配**：`本科` ↔ `大学本科`、`CET-6` ↔ `大学英语六级`、`男` ↔ `Male`、`是` ↔ `Yes`

## 🔒 隐私

- 所有档案、设置、简历附件都保存在浏览器的 `chrome.storage.local`，**不上传任何服务器**
- 仓库里**不含任何真实个人数据**：`src/common/schema.js` 出厂是空白模板，
  `examples/demo-profile.json` 是虚构的「张三」。自动化测试里也刻意只用假数据
- 权限只有 `storage` / `unlimitedStorage` / `scripting` / `contextMenus` / `tabs` / `activeTab`
  与网页访问，用于读写本地配置、在页面上执行填充、注册右键菜单、通知已开页面刷新配置
- 没有 `webRequest` / `debugger` / `proxy` / `nativeMessaging` 之类敏感权限，不含遥测
- 导出的 JSON 备份**不包含简历附件本身**，只有档案字段与设置

## 🧪 自检与测试

### 在浏览器里跑（不需要装任何东西）

打开 `tests/engine-test.html`，或在插件设置页点右上角「**识别引擎自测**」。
**90 条用例**覆盖左标签右控件表格、`thead` 表头列、`label for`、Ant Design 结构、单选组、
分区标题下的同名时间字段、日期格式改写、下拉模糊匹配，以及
「搜索框 / 验证码 / 密码 / 隐藏元素 / 无语义 name」这些**绝不能误填**的情况。

### 在命令行里跑

```bash
node tests/run-all.mjs
```

Windows 用户可直接双击 `跑测试.bat`。

| 套件 | 内容 | 结果 |
| --- | --- | --- |
| `tests/run-tests.mjs` | 识别引擎 90 条用例（自带迷你 DOM，确定性运行，不依赖浏览器） | 90 / 90 ✅ |
| `tests/test-fill.mjs` | 端到端填充：真实执行 `content.js`，校验写值、事件、select / radio / 日期 / 附件 / 撤销、可重复区块序号 | 58 / 58 ✅ |
| `tests/test-worker.mjs` | service worker：菜单注册、消息分发、多 iframe 结果汇总、按需注入 | 22 / 22 ✅ |
| `tools/verify.mjs` | 交付前静态自检：manifest、文件引用、存储键、权限、元素 id 对齐、个人数据与保留名扫描 | 全部通过 ✅ |

> 沙箱/CI 环境里 Edge 可能无法启动（mojo IPC 依赖命名管道）。
> 所以识别引擎与填充逻辑的测试都跑在**自带的迷你 DOM** 上（`tests/dom-shim.mjs`），
> 确定性、无外部依赖，任何环境都能复现。

### 想改字段字典？

编辑 `src/common/schema.js`：`aliases` 加中文别名、`weakAliases` 加英文弱别名、
`ambiguousAliases` 标记「离开分区就不能猜」的别名。改完跑一遍回归：

```bash
node tests/run-tests.mjs
node tools/build-test-page.mjs
```

然后在 `edge://extensions/` 点插件卡片上的 **🔄 刷新**，再刷新网申页面即可生效。

> 内容脚本只在页面加载时注入，**改完代码必须刷新网申页面**。

## ❓ 常见问题

**按了快捷键没反应？**
① 装完插件后要**刷新页面**；② 快捷键可能被别的扩展占用，去 `edge://extensions/shortcuts` 改；
③ `edge://` 内部页、扩展商店、PDF 预览页不允许扩展操作。

**识别到 0 个字段？**
表单可能是点按钮后才弹出的，先点开表单再触发；或字段名太特殊，去设置页「自定义字段」加一条。

**显示「选项不匹配」？**
下拉里没有对应选项。已经做了模糊匹配，还匹配不上就把档案值改成下拉里的原话。

**简历没自动上传？**
先去设置页「简历附件」选文件。部分网站的文件框是自绘组件，
浏览器出于安全不允许脚本塞文件（**这是浏览器的硬限制，任何插件都做不到**），需要手动选一次。

**填进去了但网站说没填？**
确认设置页「触发 input/change 事件」是打开的（默认打开）。若仍不行，说明控件是自绘的，手动补一下。

更多问题见 [`使用说明.md`](使用说明.md)。
